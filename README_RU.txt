JARVIS NEON — исходный код и сборка из исходников
================================================

Что лежит в архиве
------------------
- jarvis.py              основной исходный код (читаемый Python, без обфускации)
- build.bat              сборка обычного EXE без запроса прав администратора
- build_admin.bat        альтернативная сборка, которая запрашивает права администратора
- requirements.txt       список сторонних библиотек для сборки/работы
- jarvis.ico             иконка приложения
- scenarios.example.json пример пользовательских сценариев

Как проверить код
-----------------
Откройте jarvis.py в обычном текстовом редакторе или редакторе кода. В коде нет
встроенного скомпилированного payload: это обычный читаемый исходник Python.
Можно проверить синтаксис командой:
    py -3.12 -m py_compile jarvis.py

Как собрать самостоятельно на Windows
-------------------------------------
1. Установите Python 3.12 x64 с https://www.python.org/downloads/windows/ .
2. Подключение к интернету нужно, чтобы build.bat скачал библиотеки с PyPI.
3. Дважды нажмите build.bat.
4. Результат будет в dist\Jarvis.exe.

По умолчанию используйте build.bat: он НЕ запрашивает права администратора.
build_admin.bat — отдельный вариант с повышенными правами. Это полезно только,
если требуется управлять процессами, запущенными с повышенными правами; не нужно
запускать его просто так.

Как работает программа / честное описание разрешений
---------------------------------------------------
- Голосовое распознавание использует SpeechRecognition.recognize_google и передаёт
  записанную речь в сервис распознавания Google через интернет.
- Голосовой ответ использует pyttsx3; резервный механизм Windows использует
  локальный PowerShell/System.Speech. Он вызывается только при необходимости озвучить ответ.
- Открытие сайтов и интернет-поиск открывают обычные адреса в браузере пользователя.
- Завершение приложений вызывает штатную утилиту Windows taskkill; принудительное
  завершение может привести к потере несохранённых данных.
- Команда выключения компьютера требует подтверждения в интерфейсе.
- Программа ведёт журнал и хранит сценарии в %APPDATA%\JarvisNeon.
- Сценарии содержат команды, которые программа выполняет локально. Не добавляйте
  сценарии от неизвестных людей, пока не проверите их содержимое.
- В коде нет функции скрытой установки автозапуска. Сборка по умолчанию не требует
  прав администратора; build_admin.bat явно включает UAC manifest.

Пределы этой заметки
-------------------
Публикация исходного кода повышает прозрачность, но сама по себе не является
математической гарантией безопасности. Для распространения EXE желательно также
публиковать исходник, версию Python/зависимостей, SHA-256 хеш релиза и результаты
проверки антивирусом. Сборка на вашем компьютере зависит от скачиваемых версий
сторонних библиотек.
